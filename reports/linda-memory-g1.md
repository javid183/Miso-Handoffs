## Decisions I made

- Match units by `Nickname` rather than object identity, so entries survive spawned player units.
- Duo trigger hiding added (cheap, non-core, closes a bypass); not in the plan text.
- Bar subscribes lazily in `Populate` via `FindAnyObjectByType` (no static); the cached lock is dropped on disable, and a destroyed lock is re-looked-up.
- `UnlockAbilitiesSequence.SkipStep` is a no-op (completes at once).
- Optional `LockAbilitiesSequence` not built.
- Repopulating on `Changed` also resets any in-progress ability selection of the shown unit; unlocks happen in a sequence between actions, so fine.
