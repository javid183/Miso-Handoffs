- Rule: `CycloneRules.CastCooldownAfterEarlyEnd(int remaining, int coolDown, int lifePips) => Mathf.Max(0, Mathf.Min(remaining, coolDown - lifePips))`. Everything comes from data: `coolDown` = the cast's `MaxCooldown` (`Parameters.coolDown`, `coolDownV` 4 on `Lucy_Cyclone_Ability.asset`); `lifePips` = the Cyclone's `PipsTotal` (ceil of the prefab's `lifeTurns`, 3). An end counts as early when `CycloneRules.EndsEarly(_remainingTurns)` is true, which is `!Fades(...)`: life left > 0 when the Cyclone really goes.
- End paths covered:
  - **Fade** (`PhaseTick` → `Dispose`): `_remainingTurns` ≤ 0 → no refund. If the fade's dispose waits for a Whirl, Steer or pull, life stays ≤ 0, so it still gives nothing back.
  - **Burst** (`BurstRoutine` finally → `Dispose`): early → refund, applied when the Cyclone actually goes (after the 0.3 s ring).
  - **Deferred disposes** (Whirl finally ~L231, Steer finally ~L212, `DisposeWhenPullsLand` ~L280): the refund sits after the deferral checks in `Dispose`, so only the last, real dispose reaches it. A `_endRefundDone` flag stops a second run if `Dispose` is called again on the same Cyclone.
  - **Scripted end** (`Features/Onboarding/EndCycloneSequence.cs` calls `Dispose`, used by `M2River_Rush_EndLucysCyclone`): counts as an early end, so it refunds too, as the criterion's "any other non-fade end" says. See loose ends.
  - **Level teardown / scene unload**: Unity destroys the object without calling `Dispose`, so nothing runs. If a dispose does run after the level is over, `WhirlSteps.LevelEnded()` makes it skip the refund. A missing or destroyed caster, a missing orchestrator or ability list, or no cast found also skips it, without throwing. Abilities not unlocked yet (`UpgradeLevel < 0`, which would throw in `EffectSetLevel`) are skipped while looking for the cast.
- How the cast is found: `Owner` as `GUnit` → `AbilityOrchestrator.AllAbilities` → the first unlocked ability where `CycloneRules.IsCycloneCast` is true. Family Super Time's ability sits on the role handler, not in `AllAbilities`, so it is never touched.

## Decisions I made

- P1-1: "Early end" is read from the Cyclone's own life when it really goes (life left > 0), not from a separate "faded" flag. This is the same behavior as marking fades, but a fade whose dispose was deferred stays a fade with no extra state.
- P1-1: The refund runs from the final dispose, so after a burst's 0.3 s ring rather than at the moment of the burst. Both happen in the same turn, so the button shows the same.
- P1-1: The cast is found as the first unlocked `IsCycloneCast` ability in `AllAbilities` (as the plan says), not through the spawner's stat context. Locked abilities are skipped because `EffectSetLevel` throws for upgrade level −1.
- P1-1: The tests set the owner's orchestrator and the ability's preset by reflection, the way `AbilityCostOverrideTests` already does. The ability's family-turn tick is simulated by writing the private remaining-ticks field.
