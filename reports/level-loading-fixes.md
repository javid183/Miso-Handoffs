## Part 2 root cause (with evidence)

`EditorLevelLoader.LoadLevel` handed the `LevelBase` reference (a component on the prefab asset) to a deferred `EnterPlay`. `EnterPlay` first called `EditorSceneManager.OpenScene(preload scene)` and only afterwards read `AssetDatabase.GetAssetPath(level)` and `level.ID`. Opening a scene unloads unused assets, so the prefab-asset reference was already a destroyed Unity object by then: both values came out empty, `ExitingEditMode` wrote two empty EditorPrefs strings, and `ProgramFlowHandler.Start` fell into the "no fast-forward" branch (main menu).

Evidence: temporary file logging (since removed) while calling the toolbar path (`LoadLevel(level, requireIncluded: false)` on `GB_24-nook`):

```
[DIAG] EnterPlay level=null assetPath='' pending=''
[DIAG] playmode ExitingEditMode id='' path=''
[DIAG] Start id='' prefab=''
```

Before the OpenScene the same lookup returned `Assets/_Project/Content/Levels/Greybox/GB_24-nook.prefab`. The prefs were never cleared by anything else; the candidates in the plan (double handler, Teardown, Prefab Mode) were not the cause. The same bug hit the grid window's Play (same call) and the inspector button.

Fix: `LoadLevel` now reads the level id and the prefab path (asset path, else the open prefab stage) up front and passes the strings to `EnterPlay`, which no longer touches the level object.

## Dropdown behaviour (part 3)

- Favourites at the top as flat items `★ Name`, then a `Recent/` submenu (last 5 loaded or opened from the toolbar, newest first), then a separator.
- Then a toggle: `★ Favourite <level>` / `Remove <level> from favourites` (disabled when nothing valid is selected), a separator, and the folder tree by path under `Content/Levels` (e.g. `Greybox/GB_24-nook`).
- The selected level is checked wherever it appears. Favourites and recents are in EditorPrefs (`MISO.LevelToolbar.Favourites`, `.Recent`, newline-separated asset paths); entries whose prefab no longer exists are dropped when the menu opens.
- Decision: recents are a submenu rather than flat items, to keep the top of the menu short. Easy to flatten if THJ prefers.
- Selecting from the dropdown does not itself add to Recent (the plan says loaded or opened).
