# Hero `animationEvents` noise: cause (2026-11-05)

Explore, read-only, for backlog `hero-animation-events-noise`.

- **Writer (runtime, not an editor tool):** `RuntimeAbility.Initialize()` (`Core/Systems/AbilitySystem/Abilities/Runtime/RuntimeAbility.cs:237-252`) appends `{frame = abilityActivationFrame, OnActivationFrame}` to the serialized `animationEvents` list (:101). `FactionRoleHandlerBase.InitializePartially` (`FactionRoleHandlerBase.cs:96-102`) calls the full `Initialize` on `ability`/`superTimeAbility` instead of `InitializePartially` (since `200bcf02a`, 2026-08-23, FR/FST save registration). `GUnit.InitializePartially` → `AbilityOrchestrator.InitializePartially` runs on **prefab assets** (`FactionTracker.InitializePoints` :56-58 at every mission/level start; `CharacterSelectPanelUI.RefreshTotalFP` :307-309; `AbilityUpgradePanelUI` :125, :182). Domain reload off → each play adds one entry per ability to the in-memory `Unit_Linda`/`Unit_Lucy`/`Unit_John` prefabs; saving a level writes the difference as instance overrides.
- **Evidence:** every added frame = that unit's `abilityActivationFrame` (Linda 4/7, Lucy 5/99, John superTime 7). The 7 Greybox diffs contain nothing else.
- **Spread:** `animationEvents.Array` overrides in 30 committed level prefabs on `main`; `Unit_Linda.prefab` itself has 2 real events + 15 baked frame-4 entries with no calls.
- **Gameplay effect: none** (extras have no persistent calls; runtime listeners aren't serialized). Cost: list growth per play, diff noise.
- **Fix:** root: `FactionRoleHandlerBase.cs:98,:100` → `InitializePartially(orchestrator)` (keeps save registration; check no subclass needs full init; `Orchestrator` field not set there today). Hardening: `RuntimeAbility.Initialize` stops mutating the serialized list (runtime-only activation event). Cleanup after the fix: tool trimming hero lists to real events, then reverting `*.animationEvents*` overrides in level prefabs (`PrefabUtility.RevertPropertyOverride`). The 7 uncommitted Greybox diffs are 100% these overrides: `git checkout --` is safe.
